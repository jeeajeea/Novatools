# Toolzo

Toolzo is a free collection of fast, browser-based online tools designed to help students, developers, professionals, and everyday users complete common tasks without installing software.

🌐 Website: https://toolzo.online

## Features

- 📄 PDF Tools
  - Merge PDF
  - Compress PDF
  - Split PDF
  - Rotate PDF
  - Sign PDF
  - Organize PDF

- 🧮 Online Calculators
  - GPA Calculator
  - BMI Calculator
  - Age Calculator
  - Compound Interest Calculator
  - Percentage Calculator
  - Scientific Calculator
  - Unit Converter

- ⚡ Productivity Tools
  - To-Do List
  - Pomodoro Timer
  - Word Counter
  - Flashcards
  - Habit Tracker
  - Password Generator
  - Quick Notes
